# Datos del proyecto

## `synthetic/`
Contiene el dataset sintético utilizado para la validación técnica preliminar. Puede versionarse porque no contiene datos reales ni identificadores personales.

## `raw/`, `interim/` y `processed/`
Están reservadas para datos reales autorizados y se encuentran excluidas por `.gitignore`. No deben subirse a GitHub.

## Advertencia
Los datos sintéticos no representan distribuciones judiciales reales ni permiten inferencias jurídicas u organizacionales.
