# Política de seguridad y confidencialidad

Este repositorio no debe contener datos reales identificables de clientes, partes procesales o expedientes judiciales.

No publicar:

- nombres, cédulas, teléfonos, correos o direcciones;
- números reales de procesos o documentos completos;
- credenciales, tokens, archivos `.env` o llaves privadas;
- tablas de correspondencia de seudonimización;
- datos internos sin autorización expresa de GRUND Abogados LLP®.

Ante una exposición accidental, retire el archivo del historial de Git, revoque las credenciales comprometidas y comunique el incidente al responsable institucional del proyecto.
